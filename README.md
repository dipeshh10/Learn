# LearnX - Learning Management System

## 🚀 Quick Start

### Backend Server
```bash
cd backend
node src/server.js
```
**Server runs on:** http://localhost:5002

### Frontend
```bash
npm run dev
```
**App runs on:** http://localhost:5173

## 📁 Clean Project Structure
